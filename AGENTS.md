# AGENTS.md

Правила для агента в проекте anticaptcha.

## Обязанности агента

1. **Автоматически вести учётные файлы:**
   - CHANGELOG.md — факты изменений с датами
   - docs/STATE.md — текущее состояние проекта
   - docs/specs/limits.md — лимиты и ограничения

2. **Использовать Docker:**
   - НЕ устанавливать на хост (apt, pip, npm)
   - Запускать всё через `docker run` или Dockerfile
   - Bind-mount с `--user 1002:1002` для записи

3. **Проверять перед "готово":**
   - API отвечает на /health
   - Тесты проходят
   - Worker запускается без ошибок

## Текущий статус
